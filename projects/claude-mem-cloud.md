# claude-mem-cloud

## 一句话

一个围绕 Claude 记忆系统做的云端化扩展项目，重点在持久化记忆、可检索性和 Provider 扩展。

## 解决的问题

AI coding / agent 工具用久了之后，最大的损耗不是上下文窗口本身，而是跨会话连续性。重要判断被反复重建，成本高，质量还不稳定。

## 为什么选这个方案方向

常见做法是缓存更多上下文，或者把历史直接塞回模型，这两种方法都很快撞到成本和噪音问题。我没有继续扩大上下文，而是转向“持久化记忆 + 检索 + 分层取回”的方向，因为我更在意长期可用性，而不是短期堆 token。

## 我关注的效果 / 质量标准

我最关注的是记忆是否能跨会话稳定工作、检索是否足够有用、取回成本是否可控，以及系统能不能被迁移到不同 Provider 或不同运行环境中。

## 我想展示的工程判断

这个项目体现的是我对 AI 工作记忆的看法：真正有价值的不是记住一切，而是把该保留的经验压缩、组织并在正确的时候找回来。

## 技术关键词

`TypeScript` `memory system` `search` `custom provider` `context retrieval`
