# meeting-voice

## 一句话

一个面向实时跨语言沟通场景的语音翻译应用，覆盖桌面端和浏览器扩展。

## 解决的问题

实时翻译最容易被低估的不是模型能力，而是音频采集、设备切换、延迟、不同会议场景适配和用户操作成本，这些问题一起决定了它能不能真的被拿来用。

## 为什么选这个方案方向

常见做法是把离线转录或单一 API 包装成“实时翻译”，在 demo 里看起来够了，但一到真实会议就暴露短板。我没有只做模型接入，而是围绕实时音频链路和多场景入口来设计，因为我更在意可用性，而不是单次翻译效果。

## 我关注的效果 / 质量标准

我最关注的是延迟足够低、设备切换足够稳、使用门槛足够低，以及在不同平台和不同会议入口里都能保持一致体验。

## 我想展示的工程判断

这个项目体现的是我对实时产品的一种判断：真正难的不是“能翻译”，而是整条链路是否足够稳定，让用户在关键场景里敢用。

## 技术关键词

`TypeScript` `desktop app` `browser extension` `real-time translation` `audio routing`
