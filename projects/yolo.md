# yolo

## 一句话

一个统一启动 Claude Code、Codex、Gemini 等开发 CLI 的跨平台入口。

## 解决的问题

多个 AI CLI 并行使用时，真正消耗体验的通常不是模型本身，而是启动方式、认证流程、环境差异和更新路径都不一致。

## 为什么选这个方案方向

常见做法是给每个 CLI 单独写 alias 或包装脚本，短期省事，长期会越来越不一致。我没有继续堆局部封装，而是收敛成统一入口，因为我更在意操作一致性和权限体验，而不是每个工具各自“也能启动”。

## 我关注的效果 / 质量标准

我最关注的是跨平台行为尽量一致、认证链路尽量平滑、日常启动摩擦足够低，以及用户不需要反复记住每个工具的特殊约束。

## 我想展示的工程判断

这个项目体现的是我一贯的一个判断：很多表面上的工具问题，其实是入口不统一、状态不一致、心智成本过高的问题。
